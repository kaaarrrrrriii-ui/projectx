# Общие стили

`tokens.css` — единый источник цветов, радиусов и теней. В компонентах используем семантические переменные (`--color-primary`, `--color-text-muted`, `--color-border`), а новые цвета добавляем только сюда. Старые имена переменных сохранены как ссылки на палитру.

- `shared/ui` — общие кнопки, панели, заголовки, иконки, информационные карточки и навигация между шагами.
- `features/appeal` — роли и карточка выбора роли.
- `widgets` — шапка сайта, информация на главной и форма выбора роли.
- `app` — сборка экранов, параметры маршрутов и размещение виджетов.

CSS Modules отвечают за стили компонентов. Переменные размеров позволяют главной подстраиваться под высоту окна без скрытия содержимого и без изменения общих компонентов.
