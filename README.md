## 📖 О проекте

**Проблема.** Человеку, столкнувшемуся с травлей, конфликтом или давлением, часто некому высказаться. Официальные каналы требуют назвать себя, процесс непрозрачен, обратной связи нет, а страх последствий выше готовности пожаловаться.

**Решение.** «Отклик» — MVP платформы анонимных обращений с умной маршрутизацией к профильным специалистам. Заявитель описывает ситуацию своими словами или выбирает категорию, получает трек-номер и наблюдает за статусом. Оператор маршрутизирует обращение, эксперт ведёт диалог, администратор управляет справочниками и аналитикой.

### Ключевые принципы

- 🤝 **Бережный интерфейс** — поддерживающие формулировки, тон переключается вместе с типом заявителя («ты» для школьника, «вы» для родителя и педагога).
- 🔒 **Приватность по умолчанию** — без имени, почты, телефона; IP и User-Agent не связываются с обращением; EXIF и геометки вырезаются из вложений.
- 🔍 **Прозрачность** — заявитель в любой момент видит, на каком этапе обращение и что будет дальше.
- 🚨 **Кризисные обращения — не край, а норма** — детекция маркеров, приоритет в очереди, немедленная выдача контактов помощи.

### Роли

| Роль | Что делает |
|---|---|
| **Заявитель** | Создаёт обращение, ведёт диалог, подтверждает или оспаривает результат, оценивает работу |
| **Оператор** | Первая линия: приём, категория, приоритет, назначение исполнителя |
| **Эксперт** | Ведёт диалог по назначенным обращениям, готовит рекомендации, подключает коллег |
| **Администратор** | Справочники, маршрутизация, учётные записи, аналитика |

### Что реализовано в MVP

- Подача обращения — свободным текстом и по категории
- Уточняющие вопросы, вложения до 5 файлов × 10 МБ с очисткой метаданных
- Трек-номер формата `ОТК-ХХХХ-ХХХХ` с криптостойкой генерацией и rate-limit на проверку
- Полный цикл статусов: `Новое → Распределено → В работе → Нужно уточнение → Ответ готов → Завершено` (плюс ветки `Возвращено`, `Отклонено`, `Закрыто без ответа`)
- Рабочие места оператора и эксперта, внутренние заметки, соисполнители, передача обращения
- Детекция кризисных маркеров и приоритетная очередь
- Дашборд аналитики и выгрузка обезличенных CSV/XLSX

## 🚀 Быстрый старт

### TL;DR — одна команда

```bash
git clone <repo-url> projectx && cd projectx && docker compose up --build
```

Через ~30 секунд:

- 🌐 **Заявитель:** http://localhost:3000
- 🧑‍💼 **Оператор:** http://localhost:3000/operator
- 🧑‍🏫 **Эксперт:** http://localhost:3000/expert
- 🛡️ **Админ:** http://localhost:3000/admin
- 🔌 **API:** http://localhost:8080

---

### Подробная инструкция

#### 1. Требования

- Docker ≥ 24
- Docker Compose ≥ 2.20
- Свободные порты: `3000`, `5432`, `8080`

#### 2. Клонирование

```bash
git clone <repo-url> projectx
cd projectx
```

#### 3. Переменные окружения (необязательно для локального MVP)

```bash
cp .env.example .env
```

Compose содержит development-defaults и запускается без `.env`. Для собственного секрета скопируй example и измени `JWT_SECRET`:

```env
JWT_SECRET=change-me-to-a-long-random-string
```

Остальные значения уже имеют разумные дефолты:

```env
POSTGRES_USER=appuser
POSTGRES_PASSWORD=appsecret
POSTGRES_DB=appdb
NEXT_PUBLIC_API_URL=http://localhost:8080
```

#### 4. Запуск

```bash
docker compose up --build
```

Что произойдёт:

1. Поднимется PostgreSQL и применит миграции из `backend/migrations/`
2. Соберётся Go-бэкенд (multi-stage, `CGO_ENABLED=0`)
3. Соберётся Next.js-фронтенд
4. Бэкенд дождётся healthcheck'а Postgres, фронт — healthcheck'а бэкенда

#### 5. Проверка

```bash
# Все контейнеры здоровы
docker compose ps

# Логи
docker compose logs -f backend
docker compose logs -f frontend
```

Открой http://localhost:3000 — увидишь первый экран сервиса.

#### 6. Остановка

```bash
# Остановить контейнеры
docker compose down

# Остановить и удалить БД (полный сброс)
docker compose down -v
```

## 🔐 Модель приватности

- Имя, почта, телефон, учебное заведение **не запрашиваются**
- IP и User-Agent **не пишутся в БД** и не связываются с обращением (в логах веб-сервера — допустимо)
- Сторонние трекеры и аналитика **отсутствуют**
- Вложения очищаются от **EXIF и геометок** на сервере
- Сессия **не связывает** обращения одного человека друг с другом
- В аналитику и выгрузки попадают **только агрегаты и метаданные**, без текстов и контактов

**Трек-номер** — единственный ключ доступа к обращению. Формат `ОТК-ХХХХ-ХХХХ`, алфавит без визуально спорных символов (`0/O`, `1/I/l`), генерация криптостойким источником случайности, rate-limit на проверку (5 попыток в минуту с адреса).

**Уведомления.** У анонимного заявителя нет почты — по умолчанию он возвращается сам по закладке или через PWA push без привязки к личности. Опционально может оставить способ связи — только с явным согласием и предупреждением, что это снижает анонимность.
